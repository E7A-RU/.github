**Status / Статус:** Public brand policy, effective 2026-10-25. This document describes the E7A project owners' intended permission rules and is subject to applicable law. It does **not** claim that any E7A mark is registered as a trademark.

## English

### 1. Protected brand materials

The **E7A** and **E7A-RU** names as brand identifiers; official E7A logos, symbols, wordmarks, the E7A mark geometry, distinctive brand artwork, brand templates, illustrations and other official visual-identity assets (collectively **E7A Brand Assets**) are reserved by their respective rights holders.

### 2. Permission required

**Do not use E7A Brand Assets in a third-party product, service, application, interface, logo, marketing campaign, domain, package branding, merchandise or other materials without prior explicit written permission from the E7A rights holders.** This includes copying, modifying, recoloring or incorporating official E7A logos/marks in a third-party design, and any presentation that suggests official E7A affiliation, sponsorship, certification or endorsement.

Request written approval through an official contact channel published by E7A at [e7a.ru](https://e7a.ru). Authorization must describe the materials, permitted purpose, scope and duration. Silence, public download access and package installation are **not** permission.

### 3. Code and branding are separate

The published [`@e7a-ru/ui`](https://www.npmjs.com/package/@e7a-ru/ui) npm package is **publicly downloadable**, but is currently marked **`UNLICENSED`**. It is developed **internal-first, external-ready**: external developer usage is contemplated, but no blanket third-party code use, modification, copying or redistribution license is granted. Any future software license or individual written permission must be reviewed separately from brand permissions.

Even if a future UI code license permits reuse, it will **not** automatically grant permission to use E7A Brand Assets. Third-party integrations can request permission; approved neutral components and branded assets may carry different conditions.

### 4. Factual references

This policy does **not** prohibit truthful, legally permitted descriptive references to E7A (such as identifying compatibility or linking to the official project), and does not override mandatory exceptions under applicable copyright or trademark law. Do not use E7A logos, brand styling or affiliation claims to make such references misleading.

### 5. No implied license

No permission is granted by viewing public repositories, visiting E7A websites, installing an npm package, reading documentation or seeing E7A branding in a public application. All other rights are reserved.
