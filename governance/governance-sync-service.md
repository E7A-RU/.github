# Governance Sync — историческое имя первого модуля E7A Automation

**Статус:** прежнее название отдельного репозитория и сервиса **заменено**. Текущее целевое имя приватного репозитория — **`E7A-RU/automation`**, GitHub App — **`E7A Automation`**. Ни репозиторий, ни App не созданы; runtime не запущен.

**Актуальная архитектура:** [E7A Automation](engineering-automation.md).

**Governance Sync** остаётся названием первого функционального модуля внутри `automation`: контролируемая синхронизация принятых версий Governance через Draft PR. Дополнительные модули могут предлагать изменения каталога продуктов, публичного профиля `.github`, README, AGENTS, локальных схем стандартов, статусов и инженерных отчётов — всегда по ограниченному списку файлов, с отчётом о причинах изменений и без автоматического merge/deploy.

[Первоначальный узкий проектный документ (архив)](archive/governance-sync-initial-proposal-2026-10-30.md) сохранён для истории, но **не** является действующим документом для регистрации новой App или создания репозитория.

См. [Standards propagation](standards-propagation.md), [App privileges and costs](github-app-cost-and-resources.md) и [Governance release](standards-release.json).
