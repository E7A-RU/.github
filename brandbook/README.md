# E7A Brandbook — система визуальной идентичности и применения

**Статус: концепция внутреннего брендбука, 25.10.2026.** Палитра, логотипные исходники и шрифтовая пара ниже взяты из текущего E7A Core/Website. Варианты фирменной продукции, расположение знаков, размеры, метод нанесения и тиражи — **дизайн-предложения, а не выпущенные/утверждённые SKU**. Перед производством требуется брендовый и производственный review.

## Иерархия источников

1. **Фирменные исходники и реализованная геометрия** — [E7A Core / packages/ui](https://github.com/E7A-RU/core/tree/main/packages/ui), в особенности [tokens.css](https://github.com/E7A-RU/core/blob/main/packages/ui/styles/tokens.css), [E7ALogo](https://github.com/E7A-RU/core/blob/main/packages/ui/src/E7ALogo.tsx), [E7AMark](https://github.com/E7A-RU/core/blob/main/packages/ui/src/E7AMark.tsx). Публикацию внешней версии UI и применение атрибутов бренда проверять по точному source/release SHA.
2. **Визуальный референс сайта** — [Website](https://github.com/E7A-RU/website) и подтверждённая visual baseline; composition/animation сайта не копировать в merchandise без дизайна.
3. **Право использования знаков** — [E7A Brand Usage Policy](../BRAND_POLICY.md); этот документ не выдаёт лицензию сторонним лицам и не утверждает регистрацию товарного знака.
4. **Этот Brandbook** — принципы применения и концепции носителей. Если текст противоречит реальным токенам/официальной геометрии, исправлять через согласованный Core/design PR, а не создавать другую семёрку в макете.

## Задача бренда

Отразить характер E7A: инженерная ясность, уважение к вниманию, надёжность, сдержанное качество, осмысленная геометрия. Язык визуального выражения должен работать на экране, на носителях и в общении с B2C-пользователями и B2B-заказчиками, без разных несовместимых брендов для каждого продукта.

## Шрифты и голос

- **Manrope** — базовая типографика для интерфейсов и читаемых публичных материалов.
- **JetBrains Mono** — технические подписи, номера и ограниченное использование в инженерных метках (например SYSTEM 07).
- В цифровых продуктах шрифты подключаются через контролируемую конфигурацию приложения; никаких font files в git/релизную продукцию без отдельной лицензионной проверки. На печатных носителях typography и права на встраивание/печать нужно проверить.
- Голос: спокойный и содержательный. Вместо «магии», недоказанной скорости или абсолютной гарантии — понятная польза, измеримый результат, открытое указание ограничений.

## Обязательная геометрия

- **E7ALogo** — словесный E7A wordmark с фирменной цифрой 7 и синим node в реализованном CSS. Не вводить новые/самодельные модификации логотипа.
- **E7AMark** — самостоятельная геометрическая семёрка и квадратная blue balance point, shape из существующего React/SVG asset. В Core есть outline/displaced состояния; это не означает, что каждое из них является утверждённым товарным знаком для всех носителей.
- Не растягивать/не вращать/не перекрашивать «семёрку» произвольно, не заменять node другим знаком, не добавлять чужие логотипы без согласования.
- **Safe area/min size** на цифровых и печатных носителях — обязательные критерии будущего визуального acceptance по макетам, но **числа ещё не утверждены**. Проверять читаемость и контраст в натуральном размере.
- Услуга/продукт E7A может иметь свой title, но не должен без разрешения создавать новую конкурирующую геометрию E7A или выдавать third-party логотип за наш.

## Применение в digital и коммуникации

Website служит визуальной baseline, Core — источником UI и tokens. Product-specific страницы, Laboratory, Infra console, Demo и будущий Identity используют согласованные версии UI, но сохраняют собственное поведение и accessibility. Публичное B2C-позиционирование — главное на первом этапе; B2B брендируем единым стилем, а не отдельной чужой идентичностью. У Demo mock states явно помечать как demo; фирменный дизайн не является доказательством реализованной интеграции.

## Носители фирменного стиля — дизайн-референсы

1. **Стикерпак E7A (отдельный проект, обязательно разработать)** — оригинальный digital stickerpack для B2C/команды, 12 первых эмоций/состояний, версия источников, platform-specific export, авторские права и brand review; см. [Stickerpack brief](stickerpack.md).
2. **Худи E7A (обязательно)** — две концепции: минималистичная и инженерная, с фирменной семёркой; подробное размещение, материалы и варианты в [Merchandise & Hoodie](merchandise-and-hoodie.md).
3. **Футболка** — небольшая эмблема на груди, на спине только один главный акцент; тёмный и светлый пробники.
4. **Кепка** — упрощённый E7AMark для вышивки, после проверки читабельности синей точки.
5. **Шоппер/сумка для ноутбука** — крупная композиция знака, без перегруза рекламным текстом.
6. **Печатные стикеры и notebook** — точная геометрия, номерная техническая подпись; пригодно для онбординга разработчиков.
7. **Наклейка на устройство / постер / карточка продукта** — различать productId и статус live/demo, не вводить вводящих в заблуждение badges.

Макеты — **ориентиры для будущего визуального дизайна**, не фотографии существующих вещей, не лицензия третьим сторонам производить и продавать E7A merchandise. Сначала мокапы и физические пробы, затем утверждённые production files.

## Принятие брендового носителя

Проверить asset source SHA и авторизованный вариант, читаемость/контраст, адаптацию под ткань, стойкость, цветопередачу, материалы, размерную сетку, способы нанесения, права, sample review и sign-off. **Не создавать магазин и не обещать продажу мерча**, пока нет утверждённого спроса/тиража, логистики и условий возврата.

Юридические основания: [выбор формы бизнеса](../legal/business-structure-russia.md), [товарный знак, авторские права и промышленные образцы](../legal/brand-ip-and-patents-russia.md). Не выдавать Brand Policy за свидетельство о регистрации знака.

См. [Stickerpack](stickerpack.md), [Merchandise reference briefs](merchandise-and-hoodie.md) и [E7A governance philosophy](../governance/ecosystem-charter.md).
