# E7A — visual references / concept mockups

![E7A brand and merchandise visual references](./e7a-brand-reference-board.jpg)

> **Статус: исследовательский визуальный референс.** Растровая доска — moodboard направления (бренд-идентичность и мерч). Знаки, подписи и макеты на ней концептуальные: это **не официальные E7ALogo/E7AMark**, не производственные файлы и не утверждённые товары. На самой доске стоит пометка concept / not for production.

Схематическая векторная версия той же композиции: [e7a-brand-reference-board.svg](./e7a-brand-reference-board.svg). Условные знаки в SVG тоже не заменяют геометрию Core.

## Состав доски

- **Brand identity:** тёмная композиция, ориентиры палитры, Manrope / JetBrains Mono, digital, упаковка, карточки.
- **Hoodie:** Quiet Edition, Engineering Edition, Light Study — три предложенных варианта, не SKU.
- **Дополнительные носители:** футболка, кепка, шоппер, блокнот, набор наклеек и наклейка на ноутбук — концептуальные мокапы.

## Правила следующей итерации

1. Заменить условные знаки на экспортированные канонические Core assets, сохранив source SHA.
2. Подтвердить тексты и англоязычные заголовки; фразы на доске — только визуальные примеры.
3. Сделать отдельные векторные production studies для переда/спины/рукавов и проверить размеры на реальных образцах.
4. Провести brand/legal/manufacturing review до какого-либо тиража или публичной продажи.

Растр — самостоятельный moodboard (JPEG, без встроенных шрифтовых файлов). В SVG нет сторонних фотографий, файлов шрифтов и лицензируемых макетных пакетов.
